Self-Correcting ML Loop

Clusters credential text with five algorithms, scores every batch in Elasticsearch and Kibana, and promotes a new model version when quality drops.

So a model can notice when it is slipping, and correct itself.

Python scikit-learn pandas Elasticsearch Docker

Intelligent Support Center

Turns inbound emails and calls into triaged, routed, SLA-tracked tickets. The React dashboard shows live KPIs, trends, and notifications over WebSocket.

So a support lead can see friction before it becomes a backlog.

TypeScript React Node.js Express WebSocket

Resilient Food Systems

GeorgeHacks platform for coordinating food aid around disasters. React and FastAPI connect vendors, farmers, NGOs, and donors, with maps and MongoDB.

So food aid can move before, during, and after a disaster.

React FastAPI MongoDB Tailwind

AI Incident Database

TAI Hackathon project with team JVAAKOS. A pipeline cleans fragmented AI incident reports into one dataset, with a public Streamlit dashboard for trends and harm analytics.

So a policy reader can study incidents as a record, not a pile of reports.

Python Jupyter Streamlit

Crime Prediction

Python Flask scikit-learn pandas

Mask It
